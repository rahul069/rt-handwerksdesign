# RT-Handwerksdesign GbR — Website

Website for **RT-Handwerksdesign GbR**, a Darmstadt craft business doing garden, furniture and renovation work.

**Live:** [rahul069.github.io/rt-handwerksdesign](https://rahul069.github.io/rt-handwerksdesign/)

## What it does
- Presents the company's services and contact details in German
- Lightweight single-page static site that loads fast on mobile
- SEO title and meta description for local search
- Hosted on GitHub Pages

## Stack
HTML · CSS · JavaScript · GitHub Pages

## Run locally
```bash
python3 -m http.server 8000
```
